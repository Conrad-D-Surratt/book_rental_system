# 📚 Book Rental System (Streamlit Edition)

A cloud-deployed Python application for managing book inventory and rentals.

## 🚀 Features
- **Add Rental:** Log new books into the persistent database.
- **View History:** Search and sort through the full inventory using a high-performance Dataframe.
- **Resilient Backend:** Built with modular OOP logic and error-handling to ensure system stability.

## 🛠️ Architecture
- **app.py:** The Streamlit frontend and UI logic.
- **blueprints.py:** The Object-Oriented backend containing the `Book` and `DigitalBook` classes.
- **book_inventory.txt:** A pipe-delimited data file for persistent storage.
